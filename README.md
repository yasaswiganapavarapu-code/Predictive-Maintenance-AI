# Predictive Maintenance AI Website

This Streamlit web app uses the trained multiclass classification pipeline to predict a failure-type label from machine operating readings.

## Files needed
- `app.py`
- `requirements.txt`
- `best_predictive_maintenance_model.joblib` — copy this file from the folder where your training script saved it.

## Run in VS Code (Windows)

1. Keep `app.py`, `requirements.txt`, and `best_predictive_maintenance_model.joblib` in the same folder.
2. Open that folder in VS Code.
3. Open Terminal → New Terminal.
4. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Start the website:

   ```powershell
   python -m streamlit run app.py
   ```

6. Streamlit will show a local URL, usually `http://localhost:8501`. Open it in your browser.

## Important
The app expects the trained model file generated by `predictive_maintenance_multiclass.py`. If it is not in the same folder, the app will display a helpful error. The app is an academic demo, not a safety-certified industrial system.
